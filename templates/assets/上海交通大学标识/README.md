## PPT 使用要点

1. 使用所选交大源模板的实际母版与版式，保留封面和正文里原有的校名、校徽、页眉页脚及学校图形。
2. 需要补充学校元素时，优先从官方 PNG 中选择与背景、版式匹配的成品。仅修改等比尺寸和位置，校徽不另行改色或重新绘制。
3. 检查名标与图表、标题之间的安全空间，尤其留意红色或复杂背景、狭窄页脚和投影清晰度。标准红与模板主题色分别以各自官方文件为准。

官网共有 52 个附件条目，其中 A1、A2、A4 的常用校标 PNG 压缩包内容相同，整理后为 50 份不同源附件。下载原件需通过学校统一身份认证。GitHub 条目提供笔记和官方附件入口，校方源附件保存在本地。标识的使用条件见[学校管理办法（试行）](https://vi.sjtu.edu.cn/index.php/articles/bulletin/16)。可另查[官网常用文件下载](https://vi.sjtu.edu.cn/index.php/articles/bulletin/13)。
