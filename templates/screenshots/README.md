## 收录方式

- 截图存入本目录。同一套模板的多个页面按顺序编号，并在索引中归为同一项。
- 记录页面用途和可借鉴的版式特点，例如标题条、图表布局、对齐和底部来源栏。不同截图的排版思路可以组合。已有来源链接一并保留。
- 本目录随仓库公开。仅收录确认可公开的截图，含未公开资料、个人信息或研究数据的原图留在本地。
