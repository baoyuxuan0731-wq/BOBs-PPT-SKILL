# PPT 模板库

| 类型 | 入口 | 用法 |
| --- | --- | --- |
| 截图参考 | [截图索引](screenshots/) | 可以混搭标题栏、图文分栏、对齐和留白等排版思路 |
| PPTX 源模板 | [源模板索引和下载](source-templates/) | 每份成稿选一套，保持母版、主题、版式和背景来自同一套 |
| 学校标识 | [上海交通大学标识](assets/上海交通大学标识/) | 查阅交大六项 VI 基础规范、PPT 用法和官网源文件入口 |

使用本库制作汇报时，若用户未指定源模板，先询问选哪一套。若一个 PPTX 包含多套模板，先选定其中一套。已指定模板时直接使用。
