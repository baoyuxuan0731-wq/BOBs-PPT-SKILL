## 选用规则

- 制作前先确认使用哪套源模板，用户已指定时直接采用。
- 每份汇报只选一套源模板，统一使用该套的母版、主题、版式和背景。
- 2019 年汇总文件内含 5 套模板。使用时在汇总文件里选定一套。
- [截图参考](../screenshots/) 的图文布局、标题栏、对齐等设计可组合，按选定源模板重排。
